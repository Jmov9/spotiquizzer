# SpotiQuizzer
## Mikä on SpotiQuizzer ##
Spotiquizzer projektin tarkoitus on tehdä musiikkivisapeli käyttäen Spotify rajapintoja. Projektin avulla olisi tarkoitus tutustua API-rajapintoihin tarkemmin, sekä tehdä toiminnallisesti ja visuaalisesti responsiivinen sivusto. (EDIT. itse pelissä ei käytetty spotifyn rajapintaa).
